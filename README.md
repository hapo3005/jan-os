# JAN OS

Personal dashboard / life operating system.

## Status

Initial foundation: Next.js + TypeScript, responsive dashboard shell, GitHub Pages preview workflow.

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Data policy

This public repository contains code and demo data only. Personal data, credentials, API keys, tokens, calendar data, email content and financial/health information must never be committed.

Use local environment variables based on `.env.example` for future integrations.
